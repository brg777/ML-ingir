# Дашборд SOC: Анализ потока карточек

Интерактивный дашборд на базе **Taipy** и **Plotly** для визуализации и анализа потока инцидентов (карточек) SOC. 
Дашборд помогает ответить на 5 ключевых вопросов о нагрузке, качестве детекций и работе аналитиков.

## Вопросы, на которые отвечает дашборд

1. **Из чего состоит поток и как он менялся?** — динамика карточек по месяцам с разбивкой по вердиктам.
2. **Какие правила дают больше всего шума?** — интерактивный scatter-plot (объём × доля False Positive) и Топ-10 правил по абсолютному числу FP-карточек.
3. **Успевают ли взять в работу самое важное?** — доля просроченного SLA по критичности и по часам создания, а также таблица времени до закрытия по вердиктам.
4. **Когда приходит нагрузка?** — тепловая карта поступления карточек по дням недели и часам.
5. **Одинаково ли аналитики закрывают карточки?** — структура вердиктов по обезличенным аналитикам (A01, A02...).

## Требования

- **Python 3.9+**
- **Git** (опционально, для клонирования репозитория)

## Настройка окружения (venv) и запуск дашборда

Рекомендуется использовать виртуальное окружение, чтобы не засорять системный Python.


```bash
cd /полный/путь/к/проекту

python3 -m venv .venv

source .venv/bin/activate

pip install --upgrade pip

pip install taipy pandas plotly pyarrow

SOC_PARQUET=/полный/путь/к/iavd_incidents_raw_target.parquet


После запуска в терминале появится:
