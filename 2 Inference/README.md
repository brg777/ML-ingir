# SOC Trust Dashboard: можно ли доверять модели-советнику

Дашборд Taipy для руководителя SOC. Отвечает на вопрос, можно ли доверять модели курса
`lgbm_gate1__v001`, которая сортирует карточки инцидентов по вероятности того, что
инцидент реальный. Главная метрика: доля пропущенных реальных инцидентов (FN-rate).

## Что нужно для запуска

В репозиторий не входят (данные SOC и материалы курса):

1. **Датасет** `iavd_ml_dataset.parquet`.
2. **Пакет модели курса** `IAVD_3.7_ML_team` (папка, внутри которой лежит `course_ml/`).

Требуется Python 3.11.

## Запуск

Все команды выполняются из папки `2 Inference`.

```bash
cd "2 Inference"
python3.11 -m venv .venv
source .venv/bin/activate          # Windows: .venv\Scripts\activate
python -m pip install -r requirements.txt
```

Положите датасет в `data/iavd_ml_dataset.parquet` (копией или ссылкой) и укажите путь
к пакету курса:

```bash
export COURSE_DIR="/путь/к/IAVD_3.7_ML_team"      # Windows (PowerShell): $env:COURSE_DIR="C:\путь\IAVD_3.7_ML_team"
python score.py          # ~1–2 мин, создаёт data/scored.parquet
python app.py            # дашборд: http://localhost:5003
```

Если `COURSE_DIR` не задана, `score.py` ищет пакет в папке `IAVD_3.7_ML_team` рядом
с каталогом репозитория.

### Проверка корректности

В конце вывода `score.py` должна быть строка:

```
Matches model_card.md 390/107/24/2652: True
```

Это значит, что тестовый сплит окна обучения воспроизведён и совпадает с опубликованными
метриками приёмки (TP 390 / FP 107 / FN 24 / TN 2652). Если там `False`, проверьте
датасет и версию пакета курса.

`python diagnose.py` печатает все агрегаты, которые идут в дашборд, а `python smoke_charts.py`
проверяет, что графики строятся.

## Страницы

| Страница | Вопрос |
|---|---|
| Overview | KPI и вердикт: можно ли доверять |
| Q1 | Насколько хуже в эксплуатации, чем на приёмке |
| Q2 | Ранжирование стабильно, а рабочая точка при фиксированном пороге плавает |
| Q3 | Сколько работы модель создаёт аналитикам |
| Q4 | В каких срезах модель ошибается систематически |

Фильтры: порог τ, месяц эксплуатации, организация. Приёмка (тестовая часть окна
обучения) всегда считается целиком и от фильтров не зависит.

## Периоды и метрики

- **Приёмка:** тестовый сплит окна обучения 01.06–31.08.2025, рабочий порог τ = 0,0193.
- **Эксплуатация:** с 01.09.2025 до конца выгрузки (20.11.2025), модель эти карточки не видела.
  Последний месяц неполный.
- Метрики считаются только по карточкам с вердиктом «Решён» (реальный инцидент) и
  «False Positive». Доверительные интервалы: Уилсона, 95 %.

## Структура

```
app.py            интерфейс Taipy

diagnose.py       печать агрегатов для проверки
smoke_charts.py   проверка построения графиков

src/charts.py     Plotly-фигуры и KPI-плитки
src/palette.py    цвета
```

## Ограничения

- Причина деградации (падение заполненности полей «Вендор» / «Алерт») показана как
  совпадение во времени, а не как доказанная причинность.
- Приёмка получена случайным стратифицированным сплитом, эксплуатация идёт по времени,
  поэтому часть разницы может быть эффектом сплита, а не дрейфа.
- Карточки без вердикта в метрики не входят; в последнем месяце часть карточек
  может быть ещё не закрыта.
- Числа в текстовом вердикте на странице Overview записаны вручную и не пересчитываются
  при смене фильтров.
